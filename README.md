# خوابگاه‌یار 🏠

وب‌اپ مدیریت هزینه‌های مشترک خوابگاه + گروه + چت (شبیه تلگرام)

## امکانات
- ثبت‌نام با **شماره موبایل (کد پیامکی)** یا بدون شماره با **آیدی + رمز**؛ آیدی‌ها یکتا هستند
- گروه با کد دعوت؛ سازنده‌ی گروه **مادر خرج** است
- مادر خرج هزینه ثبت می‌کند و سهم هر نفر را (مساوی یا دلخواه) تعیین می‌کند
- هر عضو «پرداخت کردم» را می‌زند ← مادر خرج **تأیید یا رد** می‌کند (پرداخت نقدی را هم می‌تواند مستقیم تأیید کند)
- پیامک یادآوری برای پرداخت‌نشده‌ها: دستی (دکمه 🔔) + خودکار روزانه (فقط ساعت ۹ تا ۲۱ به وقت تهران)
- چت گروهی و پیام خصوصی (با جستجوی آیدی)، به‌صورت لحظه‌ای (Socket.IO)
- پنل مدیر در `/admin`: کاربران، بدهی‌ها، گروه‌ها، پیام‌ها، مسدودسازی
- **تماس صوتی و تصویری** گروهی و دونفره (دکمه‌های 📞 و 🎥 بالای هر چت)؛ مثل کانال صوتی دیسکورد هر کس هر وقت بخواهد به تماس جاری گروه می‌پیوندد
- زنگ ورودی، قطع/وصل میکروفون و دوربین، نشانگر «در حال صحبت»، سنجاق‌کردن هر تایل، حالت کوچک‌شده‌ی تماس
- **اشتراک صفحه** (روی لپ‌تاپ/کامپیوتر). مرورگرهای موبایل فعلاً اشتراک صفحه را پشتیبانی نمی‌کنند.

## نکات تماس
- تماس‌ها WebRTC مستقیم بین کاربران است (mesh) و تا حدود ۶ تا ۸ نفر روان است (`MAX_CALL_PARTICIPANTS`).
- روی HTTPS (که Railway می‌دهد) کار می‌کند؛ روی HTTP ساده میکروفون/دوربین باز نمی‌شود.
- اگر بعضی کاربران (مخصوصاً با اینترنت همراه) وصل نشدند، یک سرور TURN اضافه کنید: متغیرهای `TURN_URLS`، `TURN_USERNAME` و `TURN_CREDENTIAL`.

> ⚠️ مدیر می‌تواند پیام‌ها را ببیند. این موضوع در صفحه‌ی ورود و پروفایل به کاربران نمایش داده می‌شود؛ لطفاً آن را حذف نکنید.

## دیپلوی روی Railway
1. پروژه را روی GitHub بگذارید.
2. در Railway: **New Project → Deploy from GitHub repo** و ریپو را انتخاب کنید.
3. در همان پروژه: **New → Database → Add PostgreSQL**.
4. روی سرویس وب‌اپ → **Variables** این‌ها را اضافه کنید:

| متغیر | مقدار |
|---|---|
| `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` |
| `JWT_SECRET` | یک رشته‌ی تصادفی بلند |
| `ADMIN_USERNAME` | نام کاربری ادمین |
| `ADMIN_PASSWORD` | رمز قوی ادمین |
| `KAVENEGAR_API_KEY` | کلید API کاوه‌نگار (برای پیامک) |
| `KAVENEGAR_SENDER` | (اختیاری) شماره‌ی خط ارسال |
| `KAVENEGAR_OTP_TEMPLATE` | (اختیاری) نام قالب verify-lookup با یک توکن |

5. **Settings → Networking → Generate Domain** تا آدرس عمومی بگیرید.
6. جدول‌ها هنگام اولین اجرا خودکار ساخته می‌شوند. پنل ادمین: `https://دامنه-شما/admin`

اگر `KAVENEGAR_API_KEY` را نگذارید، پیامک‌ها فقط در **Logs** سرویس چاپ می‌شوند (برای تست). برای تست روی سیستم خودتان می‌توانید `ALLOW_DEV_OTP=true` بگذارید تا کد در پاسخ API هم برگردد؛ **روی سرور واقعی هرگز فعالش نکنید.**

## اجرای محلی
```bash
npm install
cp .env.example .env   # مقادیر را پر کنید
export $(grep -v '^#' .env | xargs) && npm start
```
